# Cooking Recipes Website

This website can be used to save, share and store websites. 

## Features

- Add and store recipes
- Recipes can be searched by name and category.  
- Save recipes locally in your browser
- Responsive design works on all devices

## Getting Started

### Prerequisites

You just need a modern web browser. No installation required!

### Running the Website

1. Clone this repository:
   ```bash
   git clone https://github.com/ReubenPaulClarance/cooking-recipes.git
   ```

2. Open `index.html` in your web browser

That's it! The website uses local browser storage to save your recipes.

## How to Use

1. **Add a Recipe**: Click "Add Recipe" and fill in the recipe details
2. **View Recipes**: All your recipes appear in the main list
3. **Search**: Use the search bar to find recipes by name or ingredients
4. **Delete**: Remove recipes you no longer need

## Technologies Used

- JavaScript (ES6+)
